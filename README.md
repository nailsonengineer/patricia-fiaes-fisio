# Website Profissional — Patrícia Fiaes | Fisioterapia

Website institucional, moderno, responsivo e acolhedor desenvolvido para a fisioterapeuta **Patrícia Fiaes** (CREFITO 232461-F).

## 🚀 Tecnologias Utilizadas
- **React 18** (JavaScript ES6+)
- **Vite**
- **Tailwind CSS**
- **Lucide React** (Ícones)

## 📁 Estrutura de Arquivos
Os dados da profissional, serviços, planos, vídeos e imagens estão isolados na pasta `src/data/`. Para alterar qualquer informação do site, basta editar os arquivos dessa pasta.
